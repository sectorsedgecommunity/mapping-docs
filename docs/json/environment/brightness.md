# Brightness
Brightness is primarily used for nighttime maps. It can however also be used for underground maps if desired.
::: warning
If a map has low brightness and makes heavy use of block lights, players without blocklights enabled may struggle to see other players.
:::

### Fields
**Brightness** `<float>`

Overall brightness. Defaults to 1.


**BlockBrightness** `<float>`<br />
Brightness of blocks. Defaults to 1.3.


**RainBrightness** `<float>`
<br />Value for `Brightness` when rainfall is active. Defaults to 1.
