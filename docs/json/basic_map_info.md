# Basic map info
This is the basic info about a map, such as its name, description, and dimensions.  Linear map dimensions are often X=256 Z=768.

```json
"Name": "Map name",
"Description": "Map description\nCreated by: map author(s)",
"MapSize": [ 256, 96, 768 ],
```
