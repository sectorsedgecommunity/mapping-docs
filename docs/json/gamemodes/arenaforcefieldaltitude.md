# ArenaForcefieldAltitude
`ArenaForcefieldAltitude` is a field added in 2.4.6b, after the 2023 shutdown of the game. It controls the height of where the pre-round barrier displays in Static. This is useful if the spawns on a map aren't near Y=0

**ArenaForcefieldAltitude** `<integer>`<br />
Controls altitude of the pre-round forcefield in Static. Defaults to 0.
