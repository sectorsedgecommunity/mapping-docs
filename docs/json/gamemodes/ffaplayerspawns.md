# FFAPlayerSpawns
Individual [`<positions>`](types/position.md) on a map where players can spawn in Gun Game and Head Hunter. A minimum of 12 positions is required.

## Example
```json
// FFAPlayerSpawns on Shrine
"FFAPlayerSpawns": [
	[292, 19, 339],
	[272, 19, 349],
	[239, 19, 349],
	[219, 19, 339],
	[204, 19, 324],
	[194, 19, 304],
	[194, 19, 271],
	[204, 19, 251],
	[219, 19, 236],
	[239, 19, 226],
	[272, 19, 226],
	[292, 19, 236],
	[307, 19, 251],
	[317, 19, 271],
	[317, 19, 304],
	[307, 19, 324]
],
```
